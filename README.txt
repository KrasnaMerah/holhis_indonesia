How to install this mod through Github
- Download the appropriate version from your game from the repository
- Extract the folder
- Locate the appropriate version from your game (henceforth named Folder A)
- Open the game launcher
- Create your own mod
- Place the mod on your active mod playset
- Open the mod's folder (should be on Documents > Paradox Interactive > Hearts of Iron IV > mods) (henceforth named Folder B)
- Move the contents from Folder A to Folder B
- Play the game with your mod playset
